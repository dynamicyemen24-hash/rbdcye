# تدقيق أولي لإعادة تصميم موقع رحماء بينهم

## الحالة الحالية

- المشروع هو Vite + React + TypeScript مع Tailwind CSS 4 و`motion/react` و`lucide-react`.
- الموقع مضبوط باتجاه RTL، ويحتوي على عدد كبير من الصفحات والمكونات الجاهزة.
- `AGENTS.md` يحدد هوية مؤسسة رحماء بينهم للإغاثة والتنمية باليمن، مع ألوان أساسية زمردية وذهبية، وطابع مؤسسي رزين، ومساحات بيضاء مريحة.
- الصفحة الرئيسية الحالية طويلة جدًا وتضم عدة طبقات من الأقسام، مع تحميل كسول لبعض الأقسام.
- شريط التنقل الحالي غني بالروابط والأيقونات، لكنه كثيف بصريًا ويحتاج إلى تبسيط هرمي مع إبراز التبرع.
- صفحة الإنتاج على `https://rbdcye.org` تُرجع حاليًا خطأ Vercel `DEPLOYMENT_NOT_FOUND`، لذلك سيُعاد النشر بعد اكتمال التحسينات.
- المستودع يحوي تعديلات غير ملتزمة مسبقًا على عدد كبير من الملفات؛ يجب الحفاظ عليها وعدم تنفيذ reset أو checkout شامل.

## اتجاه التحسين

- إعادة بناء الواجهة المرئية للصفحة الرئيسية مع هرمية أوضح، بطولات بصرية عالية الجودة، ومساحات بيضاء أكثر.
- الاعتماد على صور إنسانية محلية أو قابلة للتخزين المحلي، مع استخدام صور مهيأة بأحجام مناسبة و`loading`/`decoding` ملائمين.
- توحيد الأيقونات عبر `lucide-react`، وتقديم زخارف إسلامية هندسية خفيفة عبر SVG/CSS لا تطغى على المحتوى.
- تحسين الوصولية: حالات focus واضحة، أزرار لا تقل عن 44px، تسميات عربية، ودعم `prefers-reduced-motion`.
- الحفاظ على وظائف المسارات الحالية والصفحات الداخلية.
