# موقع مؤسسة رحماء بينهم الإلكتروني التعريفي
## موقع إلكتروني تعريفي رسمي لمؤسسة رحماء بينهم للإغاثة والتنمية باليمن

---

## نظرة عامة

موقع إلكتروني تعريفي حديث ومتطور تم تطويره خصيصاً لمؤسسة رحماء بينهم، يهدف إلى تعريف الجمهور بالمؤسسة ورسالتها وبرامجها، وتسهيل التواصل والتبرع المباشر.

## ما يقدمه الموقع

### للزوار والراغبين في المساهمة:
- صفحة رئيسية تعرض رسالة المؤسسة وأهدافها
- أخبار وفعاليات محدثة باستمرار
- قصص نجاح ملهمة من المستفيدين
- التبرع الإلكتروني بسهولة وأمان
- التسجيل للتطوع في المشاريع المختلفة
- صفحة اتصال للاستفسارات
- حاسبة الزكاة

### للإدارة:
- لوحة تحكم إدارية بسيطة لإدارة المحتوى
- إدارة الأخبار والإعلانات
- إدارة المشاريع
- إدارة المتطوعين والمتبرعين

## المميزات التقنية

### تصميم عصري ومتجاوب
- تصميم احترافي يعكس هوية المؤسسة
- متجاوب مع جميع الأجهزة
- واجهة عربية سهلة الاستخدام
- دعم كامل للغة العربية واتجاه RTL

### الأمان
- حماية متقدمة للبيانات والتشفير
- CSP Headers محسنة (بدون unsafe-inline)
- DOMPurify لحماية XSS
- حماية CSRF حقيقية
- Service Worker للتخزين المؤقت الذكي
- تشغيل بدون اتصال (PWA)

### الأداء
- Lazy loading للصفحات
- Code splitting محسّن
- Gzip + Brotli compression
- Self-hosted fonts مع preload
- PWA مع caching strategies متعددة

## البنية التقنية

| البند | التفاصيل |
|-------|---------|
| لغة البرمجة | React 19 + TypeScript 5 |
| التصميم | Tailwind CSS 4 + Radix UI |
| إدارة الحالة | React Context + Custom Hooks |
| قاعدة البيانات | Supabase / PostgreSQL |
| CMS | Sanity.io (Headless CMS) |
| الاستضافة | Cloudflare Pages |
| الاختبارات | Vitest |
| CI/CD | GitHub Actions |
| الحزم | pnpm |

## البدء السريع

### المتطلبات
- Node.js >= 18.0.0
- pnpm >= 8.0.0

### التثبيت والتشغيل
```bash
# تثبيت الاعتماديات
pnpm install

# تشغيل بيئة التطوير
pnpm dev

# بناء الإنتاج
pnpm build

# معاينة البناء
pnpm preview

# تشغيل الاختبارات
pnpm test

# فحص الكود
pnpm validate
```

## النشر

### Cloudflare Pages
```bash
npx wrangler pages deploy dist --project-name=rbdcye
```

### CI/CD
- GitHub Actions pipeline مع: Validate → Test → Security → Build → Deploy
- النشر التلقائي إلى Cloudflare Pages

## هيكل المشروع

```
src/
├── app/           # تطبيق رئيسي (صفحات، مكونات)
├── content/       # محتوى CMS
├── features/      # ميزات (auth, admin, news, core)
├── sanity/        # تكامل Sanity CMS
├── shared/        # خدمات مشتركة
├── styles/        # أنماط CSS
├── __tests__/     # اختبارات Vitest
└── utils/         # أدوات مساعدة
```
